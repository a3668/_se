# kcurl v0.1.0

`v0.1.0` 是 kcurl 的第一版，以 Rust 撰寫，提供基本的 HTTP／HTTPS 命令列請求功能。專案版本設定在 `Cargo.toml`，指令名稱為 `kcurl`。

## 本版功能

- 傳送 HTTP／HTTPS 請求，預設使用 GET。
- 指定 HTTP 方法，例如 POST、PUT、PATCH、DELETE、HEAD、OPTIONS。
- 設定自訂標頭，支援多個與重複標頭。
- 傳送文字、JSON 或已編碼的表單字串。
- 輸出回應本文，或同時包含 HTTP 版本、狀態碼與回應標頭。
- 將回應存入檔案，支援二進位內容與串流輸出。
- 選擇跟隨重新導向，最多 10 次。
- 設定請求逾時，並提供錯誤訊息、使用說明與版本資訊。

## 建置與安裝

需要 Rust 與 Cargo，使用支援 Rust 2024 edition 的 stable 工具鏈。在 `hw1/` 目錄執行：

```bash
cargo build --release
```

產生的執行檔位於 `target/release/kcurl`。若要安裝成可直接使用的指令：

```bash
cargo install --path .
```

Cargo 的 bin 目錄（通常是 `$HOME/.cargo/bin`）須已加入 `PATH`。

## 指令與參數

```text
kcurl [OPTIONS] <URL>
```

| 參數 | 說明 |
| --- | --- |
| `<URL>` | 完整網址，必須包含 `http://` 或 `https://` |
| `-X, --request <METHOD>` | 指定 HTTP 方法，覆寫預設方法 |
| `-H, --header <NAME: VALUE>` | 自訂標頭，可重複指定 |
| `-d, --data <DATA>` | 傳送資料；多個 `-d` 以 `&` 連接 |
| `-i, --include` | 在本文前輸出 HTTP 版本、狀態碼與回應標頭 |
| `-o, --output <FILE>` | 將回應寫入檔案；`-` 表示標準輸出 |
| `-L, --location` | 跟隨重新導向，最多 10 次 |
| `-m, --max-time <SECONDS>` | 設定逾時，預設 30 秒，支援大於 0 的小數 |
| `--timeout <SECONDS>` | `--max-time` 的別名 |
| `-h, --help` | 顯示使用說明 |
| `-V, --version` | 顯示版本，本版輸出 `kcurl 0.1.0` |

## 使用範例

取得回應本文與顯示回應標頭：

```bash
kcurl https://example.com
kcurl -i https://example.com
```

傳送 JSON：

```bash
kcurl -X POST https://example.com/api \
  -H 'Content-Type: application/json' \
  -d '{"name":"Kai"}'
```

傳送表單字串，未指定 `-X` 時自動使用 POST：

```bash
kcurl https://example.com/api -d 'name=Kai' -d 'language=Rust'
```

跟隨重新導向、儲存檔案與設定逾時：

```bash
kcurl -L https://example.com/file -o file.bin
kcurl --max-time 5.5 https://example.com
```

以上網址為用法示例，API 與檔案路徑請替換成實際目標。

## 預設行為

- 沒有 `-d` 時使用 GET；有 `-d` 時使用 POST。`-X` 優先，指定的方法會轉成大寫。
- `-d` 原樣傳送資料。未指定 Content-Type 時使用 `application/x-www-form-urlencoded`；傳送 JSON 或一般文字時須自行指定對應標頭。
- 預設只輸出本文，不額外加入換行，也不將二進位內容轉成文字。
- 預設不跟隨重新導向。使用 `-L -i` 時，只輸出最終回應的標頭與本文。
- HTTPS 保留 reqwest 預設的 TLS 與憑證檢查。
- `-o` 會覆寫已有檔案，父目錄須已存在；搭配 `-i` 時標頭也會寫入同一檔案。傳輸失敗可能留下部分內容。
- 逾時涵蓋連線與讀取回應本文，本機輸出的寫入時間不受此限制。
- 錯誤訊息寫入標準錯誤，回應內容寫入標準輸出或指定檔案。

### 結束碼

| 結束碼 | 意義 |
| --- | --- |
| `0` | 請求與輸出完成；HTTP 4xx／5xx 仍保留本文並使用此結束碼 |
| `1` | 連線、逾時、重新導向、讀取或寫入失敗 |
| `2` | 指令參數錯誤，例如無效網址、標頭或逾時值 |

標準輸出管線被下游關閉時，以 `0` 結束。

## 本版限制

- `-d` 不自動編碼、不讀取 `@檔案`，也不檢查 JSON 語法。
- 未提供檔案上傳、Cookie 儲存、Basic Auth 專用參數、代理伺服器專用參數與下載進度。
- reqwest 預設的環境變數與系統代理設定仍適用。
- 僅提供上列 curl 風格參數，未涵蓋 curl 的完整功能。
